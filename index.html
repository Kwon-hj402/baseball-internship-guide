3회차 | 야구 선수의 기초 체력과 훈련

이번 회차 목적 야구 선수에게 필요한 체력을 알아보고, 실제 선수의 훈련이 어떤 경기 동작을 준비하는지 연결해 본다.

조사 순서 기초 체력 종목 → 야구 퍼포먼스와의 관계 → 향상을 위한 구체적 운동 사례

1. 야구 선수의 기초 체력 종목 알아보기

  • 근력·몸통 지지 큰 힘을 내는 능력과 움직일 때 몸통 자세를 유지하는 능력. 하체 근력과 코어의 역할을 알아본다.
  • 하체 순발력 짧은 시간에 힘을 내어 뛰어오르거나 지면을 밀어내는 능력. CMJ(반동 점프)와 플라이오메트릭(도약·착지·반발을 활용하는 운동)을 알아본다.
  • 회전 파워 다리·골반·몸통을 연결해 빠르게 회전하며 힘을 전달하는 능력. 회전 메디신볼 던지기를 대표 사례로 본다.
  • 스피드 첫발을 내딛고 짧은 거리에서 빠르게 가속하는 능력. 최고 속도보다 출발과 첫 몇 걸음에 먼저 주목한다.

2. 각 체력 종목을 야구 퍼포먼스와 연결하기

  • 근력·몸통 지지 → 자세 유지·힘 전달 투수의 앞다리 지지, 포수의 낮은 자세와 일어서기, 타자의 스윙 중 몸통 제어와 연결해 본다.
  • 하체 순발력 → 빠른 도약·측면 이동 외야수의 점프 포구, 내야수의 좌우 이동을 예로 든다. 위로 뛰는 운동과 옆으로 뛰는 운동의 차이를 살펴본다.
  • 회전 파워 → 투구·타격 투수의 투구와 타자의 스윙에서 다리·골반·몸통이 연결되는 장면을 찾아본다.
  • 스피드 → 주루·수비 범위 주자의 도루 스타트·1루까지의 가속, 외야수의 타구 추적과 연결해 본다.

위 연결은 조사 출발점이다. 각 체력 항목이 쓰이는 경기 장면·포지션을 살펴보고, 해당 장면과 운동의 공통점을 자신의 말로 설명한다.

3. 실제 선수 영상과 대표 운동 살펴보기

먼저 볼 선수 영상 2개 실제 선수의 훈련 동작을 살펴본다.

  • 오타니 쇼헤이 — 저항 스프린트 · 19초 (MLB·Dodgers) — 밴드의 저항을 받으며 달리는 동작을 보고, 주루에 필요한 가속과 연결해 본다.
  • 지안카를로 스탠튼 — 플랭크 시연 · 59초 (MLB·Yankees) — 몸통을 지지하는 자세를 관찰한다. 선수·코치가 소개하는 홈트레이닝 영상이다.

체력 항목별 대표 영상 아래 운동을 살펴보고, 각 운동의 목적과 야구 퍼포먼스와의 관계를 알아본다.

  • 근력 트랩바 데드리프트 — Eric Cressey — 발로 지면을 밀며 일어나는 동작을 본다.
  • 하체 순발력 CMJ — VALD / 측면 바운드·방향 전환 — Eric Cressey 채널 — 수직 도약과 측면 도약의 차이를 살펴본다. CMJ 영상은 체력 평가 시연이다.
  • 회전 파워 회전 메디신볼 던지기 — Eric Cressey — 발의 이동과 몸통 회전이 던지기로 이어지는 모습을 본다.
  • 스피드 위 오타니 영상의 출발·달리기를 운동 사례로 활용한다.

선수가 그 운동을 한다는 사실과 경기력 향상 효과는 구분한다. 영상만으로 구속·타구속도·도루 기록이 좋아졌다고 단정하지 않는다.

4회차 | 야구 선수의 측정 지표·테스트·장비

이번 회차 목적 3회차에서 알아본 체력과 훈련을 바탕으로, 선수의 경기력·신체 기능·생리적 상태를 어떻게 측정하는지 조사한다.

조사 순서 측정할 지표 → 테스트 방법 → 사용하는 장비 → 야구에서의 활용

1. 알아볼 핵심 측정 항목

  • ① 야구 수행 기록·스피드 구속·타구속도(km/h 또는 mph), 배트속도, 회전수(rpm), 10 m·30 m 질주 시간(s). 투구·타격 테스트와 단거리 질주를 레이더·볼 트래킹 장비·배트 센서·타이밍 게이트로 어떻게 기록하는지 알아본다. 투구 거리, 티배팅/머신 타격, 출발 자세에 따른 측정 조건도 확인한다.
  • ② 근력·힘발휘율(RFD) 어깨 내·외회전 등척성 근력(N), 관절 토크(N·m), 최대 힘(Peak force), RFD(N/s). 핸드헬드 다이나모미터(HHD)로 어깨 근력을 재는 방법과 고정식·등속성 다이나모미터의 차이를 알아본다. 센서 위치, 관절 각도, 손 또는 벨트 고정 방식이 결과에 미치는 영향을 살펴본다.
  • ③ 점프·지면반력 CMJ 높이(cm), 지면반력(N), 충격량(N·s), 좌우 힘 차이(%). 포스플레이트 위에서 CMJ와 IMTP(등척성 미드타이 풀: 고정된 바를 당기는 검사)를 수행하고 힘–시간 곡선을 얻는 과정을 알아본다. 점프 매트·영상 앱의 점프 높이 측정과 포스플레이트 측정을 비교한다.
  • ④ 클리니컬·기능검사 어깨·고관절 내·외회전 ROM(관절가동범위, °), CKCUEST(상지 지지 자세에서 손을 교차 터치하는 검사, 횟수), Y-Balance 하체 검사(한 발 지지 상태의 도달 거리, cm·다리 길이로 정규화한 %). 각도계·경사계, 줄자·초시계, Y-Balance 키트로 측정하는 절차를 알아본다. 관절 가동성·상지 지지 능력·동적 균형이 각각 무엇을 보여주는지 구분한다.
  • ⑤ 모션캡처·근전도 관절 각도(°), 골반·몸통 회전 각속도(°/s), 동작 타이밍(ms), 표면 근전도(sEMG)의 진폭(µV 또는 정규화한 %MVC). 마커 기반·마커리스 카메라·IMU 관성센서의 측정 방식을 비교한다. 투구·스윙의 움직임 분석과 근육의 전기적 활동 측정을 구분하고, 카메라 배치·프레임률·센서 부착 위치를 확인한다.
  • ⑥ 생리학적 지표·회복 상태 심박수(HR, bpm), 심박변이도(HRV의 RMSSD, ms), 산소섭취량(VO₂, mL/kg/min), 혈중 젖산(mmol/L). 심박 센서로 안정 시·운동 중·운동 후를 기록하는 방법, 호흡가스 분석기를 이용한 점증부하검사, 젖산 측정기의 사용 상황을 알아본다. 운동 강도·심폐 체력·회복 경향을 파악하는 용도를 구분하고, 수면·주관적 피로·운동자각도(RPE)를 함께 기록하는 사례도 찾는다.

2. 테스트 절차·장비를 찾아볼 출발 자료

  • 근력·RFD VALD HHD 어깨 근력 검사 절차 / HHD의 최대 토크·토크발휘율 측정 연구 — 검사 자세와 고정 방법을 본다. 연구는 고관절을 대상으로 하므로 어깨·야구 선수에게 그대로 적용하지 않는다.
  • 포스플레이트 CMJ 검사 절차 / IMTP 검사 절차 — 준비 자세·검사 지시·반복 방법과 힘–시간 그래프를 조사한다.
  • 기능검사 CKCUEST 검사·채점 / Y-Balance 하체 검사·채점 — 자세, 터치·도달 규칙, 점수 산출법을 확인한다. ROM은 shoulder internal external rotation goniometry로 측정 시연을 찾아본다.
  • 동작·근활성 분석 Driveline 타격 평가·모션캡처 사례 / Theia 야구 마커리스 분석 / Noraxon 표면 근전도 — 촬영·센서 입력이 각도·속도·근활성 그래프로 바뀌는 과정을 본다.
  • 생리학적 측정 Polar 심박수·HRV 검사 / COSMED 호흡가스 분석 / EKF 혈중 젖산 측정 — 측정 시점과 운동 부하, 산출 지표를 확인한다.

3. 측정 결과를 비교할 때 확인할 점

  • 최대 힘과 RFD 최대 힘은 얼마나 큰 힘을 냈는지, RFD는 힘이 얼마나 빠르게 증가했는지를 나타낸다. RFD = Δ힘/Δ시간. 0–100 ms·0–200 ms처럼 계산 구간을 적고, 힘 발휘 시작점·샘플링 주파수(Hz)·필터·고정 조건을 확인한다. HHD의 RFD 측정 가능 여부는 모델과 소프트웨어별로 확인한다.
  • 측정값과 계산값 HHD의 힘(N)을 관절 토크(N·m)로 바꾸려면 모멘트암 정보가 필요하다. 모션캡처의 관절 모멘트는 모델과 추가 정보로 추정한 값이며, sEMG 진폭은 근력이 아니다. 장비가 직접 기록하는 값과 계산·추정하는 값을 구분한다.
  • 같은 조건에서 재검사 자세·워밍업·시도 횟수·휴식·측정 시각을 맞추고, 최대값과 평균값 중 무엇을 쓰는지 기록한다. 신뢰도·측정오차 자료를 찾아 작은 변화가 실제 향상인지 검토한다.
  • 야구에서의 해석 점프·근력의 변화는 구속·타구속도와 별도로 확인한다. ROM·기능검사 한 개로 부상이나 복귀 가능 여부를 판정하지 않는다. HRV는 개인의 평소 값과 비교하며, 수면·스트레스 등도 함께 살펴본다.

  • 정리 형식 측정 목적 → 지표·단위 → 테스트 절차·측정 조건 → 장비·결과 화면 → 관련 야구 장면·활용 → 한계·출처. 항목별 비교표로 정리한다.
  • 3회차와 연결 근력·몸통 지지, 하체 순발력, 회전 파워, 스피드를 각각 어떤 검사로 평가할지 연결한다. 생리학적 지표와 기능검사는 선수 상태를 함께 파악하는 자료로 배치한다.

5회차 | 스포츠 비전·반응·인지 훈련 도구

이번 회차 목적 야구 선수가 공을 보고 판단하고 움직이는 데 필요한 능력을 알아보고, 이를 훈련하는 과제·도구·평가 지표를 조사한다.

조사 순서 필요한 시각·인지 능력 → 훈련 과제와 규칙 → 사용하는 도구·측정 지표 → 야구에서의 활용

1. 알아볼 핵심 훈련 항목

  • ① 반응등·선택 반응 BlazePod·FITLIGHT처럼 불이 켜지면 터치하는 도구를 알아본다. 정해진 위치의 불에 정해진 동작으로 반응하기(단순 반응), 색에 따라 다른 손·방향으로 움직이기(선택 반응), 특정 색에만 반응하기(Go/No-Go)를 비교한다. 점등부터 터치까지의 시간(ms), 정답률(%), 잘못 누른 횟수·놓친 횟수를 확인하고, 수비 첫발·상황에 맞는 이동과 연결해 본다.
  • ② 시각 차단·예측 Senaptec Strobe의 투명·불투명 전환을 이용한 포구 훈련과 temporal occlusion(투구 영상을 특정 시점에서 가리는 과제)을 알아본다. 안경은 전환 주기·투명/불투명 시간, 영상은 공 릴리스 기준 차단 시점을 확인한다. 포구 성공률, 구종·코스 판단 정확도(%)를 기록하고, 제한된 시각 정보로 공의 궤적을 예측하는 상황과 연결해 본다.
  • ③ 주의·억제·추적 Stroop의 congruent/incongruent(글자 뜻과 글자색의 일치/불일치), task switching(판단 규칙 전환), NeuroTracker의 multiple object tracking(여러 이동 표적 추적)을 알아본다. 반응시간·오류율, 규칙 전환 시 추가 시간(ms), 표적 추적 정확도·속도 역치를 비교한다. 방해 정보 속에서 필요한 단서를 고르는 능력과 야구의 주자·타구·수비 상황 파악을 연결해 본다.
  • ④ 손–눈 협응·야구 판단 HECOstix·Vector Ball의 색 지시 포구와 투구 영상의 swing/take(칠지 지켜볼지) 판단을 알아본다. 색을 보고 지정된 부분을 잡는 과제, 구종·코스를 보고 스윙 여부를 정하는 과제의 규칙을 정리한다. 포구 성공률·지시 준수율·스윙 판단 정확도(%)를 구분하고, 일반 협응 과제와 실제 타격·수비의 공통점·차이를 살펴본다.

2. 도구·과제를 찾아볼 출발 자료

  • 반응등 BlazePod Random 공식 시연 / FITLIGHT Go/No-Go 과제 설명 — 점등 설정, 반응할 색·무시할 색, 터치 방식과 결과 화면을 확인한다.
  • 스트로보 안경 Senaptec Strobe 야구 공식 영상 / Senaptec 야구 적용 사례 — 안경을 쓰고 수행하는 동작과 난이도 조절 방식을 본다. 업체의 효과 설명과 연구에서 확인한 결과는 구분한다.
  • 인지·추적 과제 PsyToolkit Stroop 설명·시연 / NeuroTracker 과제 진행 방식 — 자극 제시 → 판단·추적 → 응답 → 점수 표시 순서로 정리한다.
  • 협응·구종 판단 HECOstix·Vector Ball 훈련 자료 / 투구 영상 차단을 이용한 지각 훈련 연구 — 색 지시·포구 규칙과 영상 차단 시점·응답 방법을 확인한다.
  • 추가 검색어 baseball choice reaction Go No-Go drill / stroboscopic baseball catching drill / Stroop congruent incongruent task switching / baseball pitch recognition temporal occlusion. 영상은 demo·tutorial, 효과 연구는 controlled trial·transfer를 붙여 찾는다.

3. 훈련 결과를 비교할 때 확인할 점

  • 반응시간에 포함된 동작 불이 켜진 뒤 터치하기까지의 시간에는 자극을 알아보고 판단하는 시간과 손·몸을 이동하는 시간이 함께 들어갈 수 있다. 장비 간 거리·배치, 사용하는 손·발, 출발 자세를 확인한다.
  • 속도와 정확도 시간이 짧아져도 오반응이 늘 수 있다. 반응시간과 정답률·오류·누락을 함께 보고, 같은 과제 규칙과 난이도에서 비교한다.
  • 과제 이름과 실제 규칙 Stroop은 글자 뜻과 글자색의 간섭을 다루며, 특정 색만 누르는 과제는 Go/No-Go에 해당한다. 스트로보 안경의 반복 차단과 영상의 특정 시점 차단도 각각의 방식으로 설명한다. NeuroTracker 점수는 해당 추적 과제의 속도 역치이며 제품의 점수 정의를 확인한다.
  • 훈련 향상과 경기 전이 훈련한 과제 점수 향상 → 다른 검사에서의 향상 → 실제 타격·수비 향상을 나누어 정리한다. 연구의 대상·훈련 기간·비교군·평가 항목을 확인하고, 여러 도구를 함께 쓴 연구에서는 한 도구의 효과로 단정하지 않는다.

4. 조사 범위·정리 형식

  • 조사 범위 위 네 가지 훈련 항목을 모두 알아본다. 각 분야의 대표 도구·과제 사례를 포함하고, 실제 동작·화면·규칙이 보이는 영상 3개와 훈련 효과를 비교한 연구 1개 이상을 찾아 정리한다.
  • 정리 형식 훈련 목적 → 제시 자극 → 판단 규칙 → 반응 동작 → 도구·화면 → 지표·단위 → 관련 야구 장면·활용 → 근거·한계·출처. 도구·과제별 비교표로 정리한다.
  • 3·4회차와 연결 움직임의 힘·속도를 훈련한 3회차, 이를 측정한 4회차에 이어, 이번에는 무엇을 보고 언제 어떤 행동을 선택하는지에 주목한다. 수비 첫발, 포구, 구종·코스 판단, 스윙 여부 결정에 적용할 수 있는 요소를 설명한다.

6회차 | 야구 관람 전·경기장 안의 경험 탐색

이번 회차 목적 사람들이 야구를 보러 가기로 결정한 때부터 경기장 안에서 시간을 보내기까지 어떤 경험을 하는지 조사한다. 팬의 행동·감정·필요한 정보와 주변 서비스·운영을 함께 살펴보며, 아직 알지 못했던 경험을 발견한다.

조사 흐름 경험을 넓게 수집 → 시간순으로 경험 지도 작성 → 사람·조건에 따른 차이 비교 → 새로 발견한 경험을 따라 추가 조사 → 관련 산업·운영 주체 연결

가이드 사용법 아래 큰 단계는 모두 살펴본다. 세부 항목은 관찰을 돕는 예시이며, 정해진 문제 목록이나 전부 답해야 하는 체크리스트가 아니다. 예시에 없는 행동·즐거움·불편·의외의 상황도 조사자가 직접 추가한다. 먼저 문제를 정해 놓고 그에 맞는 후기만 찾지 않는다.

1. 관람을 결정하고 준비하는 경험

  • 조사 분야 야구에 관심을 갖는 계기, 경기·구단·구장 선택, 동행자와 일정 조율, 정보 탐색, 예매·결제, 준비물·예산·교통 계획. 관심이 생겼지만 실제 방문으로 이어지지 않은 경험도 포함한다.
  • 관찰을 돕는 예시 처음 가는 사람이 정보를 얻는 곳, 좌석을 고를 때 중요하게 보는 조건, 함께 앉기 위한 조율, 예매 성공·실패 이후 행동, 날씨에 따른 준비, 응원도구·음식·짐을 미리 마련하는 방식. 준비 과정에서 생각보다 오래 걸리거나 다른 사람의 도움이 필요한 일도 찾는다.
  • 비교할 맥락 첫 방문·반복 방문, 혼자·친구·가족, 홈·원정, 즉흥 방문·미리 계획한 방문. 같은 표를 사더라도 원하는 경험과 필요한 정보가 어떻게 달라지는지 살펴본다.
  • 연결할 산업 구단·예매 플랫폼·결제 서비스·여행·교통·숙박·상품 판매·팬 정보 콘텐츠. 실제 경험에서 등장한 사업자와 역할을 표시하고, 목록에 없는 주체도 추가한다.

2. 경기장으로 이동하고 입장하는 경험

  • 조사 분야 집·직장·학교에서 출발, 이동 중 정보 확인, 주변 상권 이용, 동행자 만나기, 주차·하차, 입장 준비, 게이트·좌석 찾기. 경기장 경계 밖에서 일어나는 경험도 포함한다.
  • 관찰을 돕는 예시 약속 장소를 정하는 방식, 이동 중 일정 변경, 모바일 티켓·배터리·통신 상태, 반입 물품 확인, 짐·유모차를 동반한 이동, 안내 표지·직원 도움, 서로 다른 입장 동선. 단순 이동뿐 아니라 기대감·혼란·기다리는 동안의 행동을 본다.
  • 살펴볼 자료 출발부터 입장까지 담긴 브이로그·방문기, 지도·표지 사진, 교통·주차·입장 안내. 실제 경로 위에 사용한 정보와 장소를 표시하고, 화면상의 경로와 현장에서의 행동을 비교한다.

3. 경기장 안에서 시간을 보내는 경험

  • 경기 보기·이해하기 좌석·시야·자세·공간, 전광판·소리·중계·기록 정보, 규칙 이해, 응원과 경기 집중, 자리를 비운 동안의 경기 확인. 같은 좌석·안내가 누구에게 편리하고 누구에게 다르게 느껴지는지 살펴본다.
  • 먹고·사고·쉬기 음식·음료·굿즈·체험의 탐색·구매·사용, 화장실·휴식·수유·충전·짐 보관, 동행자 돌봄. 판매 품목뿐 아니라 손에 든 물건, 자리와 매장 사이 이동, 기다리는 동안의 행동까지 관찰한다.
  • 공간·환경과 함께 지내기 햇빛·비·온도·소음·혼잡, 위생, 쓰레기·분리배출·다회용기 반환, 통로·계단·안전·도움 요청. 쓰레기가 생긴 순간부터 처리될 때까지처럼 눈에 잘 띄지 않는 과정도 따라가 본다.
  • 다른 사람과 어울리기 응원 문화, 일어서기·이동·자리 사용, 사진 촬영, 이벤트·팬 서비스, 주변 관객·직원과의 상호작용. 함께 즐기는 경험과 기대가 달라 부딪히는 경험을 모두 찾는다.
  • 보여지고 기록되는 경험 전광판·현장 카메라·방송 중계·다른 관객의 SNS 촬영을 구분한다. 촬영 참여를 즐기는 경우와 원치 않는 얼굴·동행자 노출, 촬영 사실을 알게 되는 시점, 안내·선택·문의 과정 등 서로 다른 경험을 살펴본다. 노출 경험, 안내 내용, 법적 판단을 한데 섞지 않는다.
  • 관찰 범위 확장 위 분류에 들어가지 않는 경험도 별도로 적는다. 어린이·고령자·외국인·장애인 관람객 등 다양한 이용자의 실제 사례를 찾아, 자신의 관람 경험만으로 전체를 설명하지 않는다.

4. 스스로 조사 범위를 넓히는 방법

  • 처음에는 전체 경험 보기 ‘[구장명] 첫 직관’, ‘야구 직관 하루 브이로그’, ‘가족 야구장 방문’, ‘원정 직관 여행’처럼 넓게 검색한다. 처음부터 ‘불편·실패’만 검색하지 말고, 사람들이 실제로 무엇을 하는지 시간순으로 적는다.
  • 발견한 행동에서 가지 뻗기 원자료에 나온 행동·물건·장소·감정을 검색어로 삼아 다른 이용자 경험을 찾는다. 물건을 들고 이동하는 장면을 봤다면 구매·보관·사용·처리와 관련된 경험으로 넓힐 수 있다. 새로운 항목의 이름과 추가한 이유는 조사자가 작성한다.
  • 여러 관점으로 다시 보기 시간·비용 / 정보·선택 / 몸·공간·접근성 / 사람·감정·관계 / 안전·환경 / 촬영·정보 노출을 관찰 관점으로 활용한다. 하나의 경험을 여러 관점에서 보되, 모든 관점을 억지로 채울 필요는 없다.
  • 자료 대조 실제 이용자 경험과 공식 안내·현장 사진·영상·운영 자료를 대조한다. 편집된 영상으로 실제 대기시간을 추정하지 않고, 확인할 수 없는 부분은 남겨 둔다. 인터뷰를 한다면 최근 방문에서 실제로 한 일을 시간순으로 듣는다.
  • 산업과 연결 경험에 등장한 구단·시설·판매점·예매사·방송사·청소·보안·교통·주변 상권의 역할을 연결한다. 고객이 원하는 것, 운영에 필요한 공간·인력·정보·비용, 서로 다른 주체의 이해관계를 구분한다. 불편의 원인은 자료로 확인하기 전까지 가설로 둔다.

5. 자료 탐색 출발점

  • 예매·구장 정보 KBO 구단별 티켓 안내 / 좌석·입장권 안내 사례 — 조사할 구단의 공식 안내와 실제 방문 경험을 연결한다.
  • 안전·접근성 KBO 경기장 안전가이드라인 / 시각장애인 현장 관람 지원 사례 — 어떤 경험을 지원하기 위해 마련된 제도·서비스인지 살펴본다.
  • 자원·쓰레기·운영 서울시 야구장 다회용기 안내 — 이용자 행동과 수거·세척·재사용 과정으로 조사 범위를 넓힌다. 실제 이용 경험은 별도 자료로 확인한다.
  • 촬영·노출 조사 구단의 티켓 약관·현장 촬영 안내, 방송사·플랫폼의 문의·신고 안내를 찾아본다. 해외 구단 티켓 약관 사례는 안내 방식을 비교하는 참고 자료이며 국내 적용 여부를 뜻하지 않는다.
  • 출처 확장 공식 자료에서 발견한 용어를 이용 후기·영상·현장 관찰로, 이용 후기에서 발견한 행동을 공식 안내·운영 자료로 연결한다. 링크에 있는 사례만으로 조사를 끝내지 않는다.

6. HTML 보고서 목차·정리 형식

  • 1. 조사한 사람·상황·자료 방문 경험, 동행자, 구장·날짜, 관찰·후기·영상 등 자료의 범위
  • 2. 관람 전 경험 지도 관심·결정 → 준비·예매 → 이동·입장에 이르는 행동과 사용한 서비스
  • 3. 경기장 안의 경험 지도 관람·소비·편의·환경·관계·노출 등 실제 자료에서 발견한 경험
  • 4. 조사자가 새로 발견한 경험 예시에 없던 항목, 예상과 달랐던 행동, 조사 범위를 넓힌 과정
  • 5. 사람·조건별 차이와 산업 구조 같은 상황의 다른 경험, 관련 사업자·운영 주체·자원·비용
  • 6. 더 알아볼 경험과 근거 반복 관찰된 현상, 만족·불편·현재 대처 방식, 아직 설명되지 않는 점

경험 기록 형식 상황·사람 → 실제 행동 → 사용한 정보·장소·물건·서비스 → 느낀 점·결과 → 관련 주체 → 근거·날짜 → 추가 발견. 불편이 확인된 경우에만 시간·돈·기회 등의 영향을 붙인다. 이 단계에서 해결책이나 사업 아이템을 확정하지 않는다.

7회차 | 경기 종료 후·일상 속 야구 경험 탐색

이번 회차 목적 경기 종료 뒤 귀가·정리·공유·재방문으로 이어지는 경험과, 경기장에 가지 않는 날 야구를 즐기는 방식을 조사한다. 6회차 경험 지도를 확장해 야구 산업이 팬의 일상과 주변 사람·지역에 어떻게 연결되는지 이해한다.

조사 흐름 경기 종료 전후의 행동 → 귀가·후속 처리 → 기억·공유·일상 활동 → 다시 참여하거나 멀어지는 과정 → 경험 간 연결과 새로운 조사 분야 발견

가이드 사용법 아래 큰 단계는 모두 탐색하되, 세부 예시는 출발점으로 사용한다. 문제의 종류·개수나 조사 결론은 미리 정하지 않는다. 좋은 경험, 아무 일 없이 지나간 경험, 계획이 달라진 경험을 함께 보고 조사자가 새 항목을 추가한다.

1. 관람을 마무리하고 경기장을 떠나는 경험

  • 조사 분야 언제 떠날지 결정하기, 동행자와 만나기, 짐·구매 물품 정리, 쓰레기·다회용기 처리, 화장실·매장·이벤트 마지막 이용, 출구·주차장·정류장 이동. 마지막 아웃 이후뿐 아니라 미리 떠나는 사람의 경험도 조사한다.
  • 관찰을 돕는 예시 끝까지 응원하고 싶은 마음과 귀가 계획의 조율, 인파 속 동행자 찾기, 늦은 시간의 시설 이용, 남겨진 물건·쓰레기, 직원의 정리·안내, 경기 후 주변 상권에 머무는 행동. 경기 결과·날씨·행사·동행 조건에 따른 차이를 본다.
  • 관점 확장 떠나는 관람객뿐 아니라 청소·매장·보안 직원, 주변 주민·상인이 경험하는 경기 종료도 살펴본다. 관객에게 편리한 선택이 다른 주체의 작업·혼잡·비용과 어떻게 연결되는지 자료로 확인한다.

2. 집이나 다음 목적지로 이동하는 경험

  • 조사 분야 귀가 경로 선택·변경, 도보·대중교통·택시·자가용·원정버스, 환승·동행자 배웅·숙박, 이동 중 경기 확인·연락, 도착 후 일정. 구장 출구부터 최종 목적지까지 전체 경로를 따라간다.
  • 관찰을 돕는 예시 연장전·우천 지연 등으로 예상보다 늦게 끝난 경기, 막차·환승 연결과 관람 종료 시점의 조율, 출차·승차 대기, 택시·숙박으로 계획 변경, 어린이 동반 귀가, 다음 날 출근·등교와의 관계. 이런 상황이 실제로 생겼는지, 별다른 어려움 없이 귀가한 경우와 무엇이 달랐는지 확인한다.
  • 살펴볼 자료 실제 경기 종료 시각·방문 날짜, 퇴장 동선, 해당 요일·방향의 교통 시간표, 마지막 환승 조건, 이동 후기·영수증·교통 안내. 영상 속 시각이 확인되지 않으면 추정하지 않는다. ‘막차를 못 탔다’는 한 문장에 그치지 않고 어떤 선택과 이동이 이어졌는지 재구성한다.
  • 연결할 산업 구단·경기장, 도시철도·버스·택시·주차 운영, 지도·교통 정보 서비스, 여행·숙박·주변 상권. 출발 전 안내부터 실제 귀가까지 서비스가 어디서 이어지고 끊기는지 살펴본다.

3. 경험을 정리하고 다른 사람과 공유하는 과정

  • 조사 분야 사진·영상·티켓·굿즈 보관, 놓친 장면 다시 보기, 동행자와 비용 정산, 후기·SNS·커뮤니티 활동, 구매 상품 관리, 분실물·문의·환불·교환 등 관람 후 남는 일. 즐거움을 오래 유지하는 방법과 정리가 필요한 일을 함께 본다.
  • 관찰을 돕는 예시 자신이 본 장면 찾기, 사진을 함께 모으는 방식, 온라인에 올라온 자신의 모습이나 동행자 노출을 뒤늦게 알게 된 경험, 문의처 찾기, 유니폼 세탁·보관·수선, 기념품 수집. 직접 선택한 공유와 타인의 게시·재공유를 구분한다.
  • 관점 확장 같은 사진·영상·기록이 누군가에게 추억·정보·수익원이 되고 다른 사람에게는 부담이 되는 맥락을 살펴본다. 팬·구단·방송사·콘텐츠 제작자·플랫폼·판매자의 역할과 현재 대응 방법을 비교한다.

4. 경기장 밖에서 야구를 계속 즐기거나 멀어지는 경험

  • 콘텐츠·정보·관계 중계·하이라이트·숏폼·기록·게임, 선수·구단 소식, 팬 커뮤니티·함께 보기·응원 모임을 탐색한다. 어떤 순간에 무엇을 선택하는지, 시청·참여를 시작하거나 중단하는 계기와 생활 속 시간 배분을 본다.
  • 구매·수집·직접 참여 굿즈·선물·멤버십, 체험 시설·캐치볼·취미야구·지역 행사 등 야구를 즐기는 방식을 넓게 찾아본다. 기존 팬의 반복 이용뿐 아니라 관심은 있지만 참여하지 않는 사람, 방문·구매를 포기한 경험도 포함한다.
  • 다음 관람으로의 연결 다시 갈지 결정할 때 떠올리는 경험, 함께 갈 사람·날짜·구장 선택, 준비 방식의 변화, 새 팬에게 전달하는 조언을 조사한다. 승패 외에 관계·이동·소비·편의·기억이 다음 행동에 어떻게 연결되는지 본다.
  • 새 분야 발견 위 범주에 맞춰 자료를 억지로 나누지 않는다. 실제 경험에서 새로운 활동·서비스·주체가 나타나면 별도 항목으로 추가하고, 관련 이용 과정과 산업을 더 찾아본다.

5. 자료를 찾고 경험을 비교하는 방법

  • 넓은 자료 수집 ‘야구 직관 끝나고’, ‘원정 직관 귀가’, ‘야구팬 일상’, ‘직관 후기’, ‘야구 입문·탈덕·재입문’, ‘경기 없는 날 야구팬’ 등에서 시작한다. 자료에 등장한 행동·장소·서비스·예상 밖 상황을 새 검색어로 연결한다. 불편을 찾기 위한 단어만 반복 검색하지 않는다.
  • 대조할 조건 가까운 지역·장거리 원정, 일찍 출발·끝까지 관람, 혼자·다양한 동행자, 평일·휴일, 경기 종료 시각, 온라인·현장 경험을 비교한다. 한 사람의 여러 게시물과 서로 다른 사람의 경험을 구분한다.
  • 출발 자료 KBO 경기일정·결과에서 조사 경기를 확인하고, 세부 경기 기록과 해당 지역 교통기관의 시간표·당일 공지를 함께 찾는다. 구장 주차 안내 사례는 실제 출차·귀가 후기와 대조한다.
  • 일상 경험의 출발점 중계·영상 서비스 / 상품 사용·구매 후 문의 사례 / 생활야구 커뮤니티 / 야구 체험 사례. 서비스 소개에서 시작하되, 실제 이용자 경험과 다른 대안으로 조사를 넓힌다.
  • 운영 자료 연결 실제로 발견한 경험과 관련된 공지·문의 답변·운영 매뉴얼·채용 업무·입찰·사업 자료를 찾는다. 관련 인력·공간·시간·비용과 주체 간 역할을 파악하되 공개되지 않은 계약·수익·원인은 단정하지 않는다.

6. 경험 조사에서 Problem 후보로 이어가기

  • 전체 지도부터 완성 6회차와 합쳐 관람 결정 → 준비·이동 → 경기장 경험 → 마무리·귀가 → 공유·일상 → 다음 참여의 흐름을 만든다. 조사 중 새로 발견한 경험과 아직 자료가 없는 구간을 표시한다.
  • 문제는 자료에서 도출 반복되는 기대와 실제 결과의 차이, 예상하지 못한 대처 행동, 특정 조건에서 커지는 부담을 묶어 본다. 확인되지 않은 원인·규모·구매 의사는 가설로 둔다. 모든 경험을 문제로 만들거나, 예시에 있는 문제를 억지로 채택하지 않는다.
  • Problem 후보 기록 어떤 사람이 어떤 맥락에서 무엇을 하려 했는지 → 실제로 무엇이 일어났는지 → 어떤 영향을 받았는지 → 현재 어떻게 대처하는지 → 근거와 남은 불확실성. 문제의 이름은 조사자가 붙이고 기존 서비스·운영 방식이 이미 해결하는 부분도 함께 적는다.
  • 산업 이해와 연결 관련 고객·사업자·기관, 이들이 제공하는 가치와 부담하는 비용, 이미 이용되는 대안을 표시한다. 사업으로 다룰 가능성은 이후 검증할 항목으로 남긴다. 이번 과제는 경험을 이해하고 문제 후보의 근거를 쌓는 단계다.
